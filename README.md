# kos-sdk-checks

Small programs that check how KasperskyOS Community Edition 1.4.0.102 behaves against POSIX and Linux, with their
output on KasperskyOS (under QEMU) and on Linux for comparison.

They come from porting .NET NativeAOT to KasperskyOS ([runtime-kos](https://github.com/caraioniurie47/runtime-kos)),
where each difference found needed a workaround or a test change. The programs and their results are being checked
again before they are added here.
